📌 1. ภาพรวมของระบบ (System Overview)

ระบบสคริปต์ Cronjob นี้ทำหน้าที่ดึงข้อมูลธุรกรรมการขายและใบเสร็จ/บิลจากฐานข้อมูลระบบใหญ่ (MSSQL Server) เข้ามายังฐานข้อมูล MySQL ของเว็บแอพพลิเคชัน SAC เพื่อใช้ในการประมวลผล รายงาน และแสดงผลบน Dashboard

  • 📄 import_data_bill_sac.php

    ดึงข้อมูลเอกสารบิล (Document Bill) จาก MSSQL ย้อนหลัง 1 วัน (Yesterday ถึง Today) นำมา INSERT หรือ UPDATE ลงในตาราง ims_document_bill ใน MySQL

  • 📊 import_data_sale_sac_today.php

    ดึงข้อมูลการขายสินค้ารายวัน (Product Sale Sac) ของวันนี้ นำมาประมวลผลแยกกลุ่มสินค้า (PGROUP), สาขา (BRANCH) และปรับแต่งยอดติดลบ แล้วบันทึกลงตาราง ims_product_sale_sac

⚡ 2. เทคนิคการเพิ่มความเร็วการทำงาน (Performance Optimization Techniques)

1. Pre-fetching & Memory Key Lookup (O(1))

แทนที่จะส่งคำสั่ง SELECT ไปถาม MySQL ทีละแถวในลูป (N+1 Problem) ระบบจะดึงรายการ Key ทั้งหมดที่มีใน MySQL ออกมาเก็บใน PHP Array แล้วใช้ isset($array[$key]) ตรวจสอบข้อมูลใน Memory แทน ซึ่งใช้เวลาเพียง 0.00001ms

2. Prepared Statements Outside Loop

เตรียมโครงสร้างคำสั่ง SQL (prepare()) ของคำสั่ง CHECK, INSERT และ UPDATE เพียงครั้งเดียวนอกลูป แล้วส่งเฉพาะค่า Parameter ไป execute ในลูป ช่วยลด Overhead การ Parse SQL คำสั่งซ้ำๆ

3. Database Transaction Grouping

ครอบลูปประมวลผลด้วย $conn->beginTransaction() และ $conn->commit() บันทึกข้อมูลทั้งหมดลง Disk ในคราวเดียว ลด Disk I/O Write Operations จากหลายร้อยครั้งเหลือเพียง 1 ครั้ง

4. Smart Cleanup Query Check

ในสคริปต์ import_data_bill_sac.php ปรับคำสั่งลบข้อมูลที่ไม่สมบูรณ์ด้วยการเช็ก SELECT 1 ... LIMIT 1 ก่อน หากไม่มีแถวเสีย จะข้ามคำสั่ง DELETE ทันที ไม่ต้อง Scan ตาราง 530,000+ แถวทุกครั้ง

📈 3. ตารางเปรียบเทียบก่อนและหลังการปรับปรุง

หัวข้อวัดผล แบบเดิม (Unoptimized) แบบปรับปรุงใหม่ (Optimized)
SELECT Queries ในลูป N ครั้ง (ตามจำนวนแถว) 0 ครั้ง (Pre-fetched เข้า Memory)
การ Prepare SQL Prepare ใหม่ทุกรอบในลูป Prepare ครั้งเดียว ก่อนเข้าลูป
Disk Commit Overhead Auto-commit ทุกแถว (High Disk I/O) Batch Commit ครั้งเดียวตอนจบ (Transaction)

💻 4. วิธีการรันสคริปต์และการตั้งค่า Cronjob / BAT File

4.1 การสั่งรันผ่าน Command Line (Manual Run)

เปิด Terminal / Command Prompt แล้วไปยังโฟลเดอร์ cronjob จากนั้นใช้คำสั่ง:

# นำเข้าข้อมูลบิลเอกสาร
php D:\website\sac_data2\cronjob\import_data_bill_sac.php

# นำเข้าข้อมูลยอดขายวันนี้
php D:\website\sac_data2\cronjob\import_data_sale_sac_today.php

4.2 การรันผ่าน BAT File ใน Windows Task Scheduler

ไฟล์ batch (.bat) สำหรับใช้ตั้งเวลาใน Windows Task Scheduler:

  • import_data_bill_sac.bat -> เรียกใช้ import_data_bill_sac.php
  • import_data_sale_sac_today.bat -> เรียกใช้ import_data_sale_sac_today.php

🛡️ 5. ข้อควรระวังและการดูแลรักษา (Maintenance & Safety)

  • การ Rollback เมื่อเกิดข้อผิดพลาด: ทั้งสองสคริปต์ถูกหุ้มด้วย try ... catch หากการเขียนข้อมูลกลางทางเกิดความผิดพลาด ระบบจะเรียก $conn->rollBack() เพื่อยกเลิกรายการทั้งหมด ป้องกันข้อมูลค้างแบบกึ่งสำเร็จกึ่งล้มเหลว
  • การตรวจสอบเวลาประมวลผล: ตอนท้ายสคริปต์จะมีบรรทัด Execution time: X.XXXX seconds เพื่อให้สามารถติดตามความเร็วการทำงานและตรวจสอบปัญหาความช้าของระบบ Network/Database ได้ง่าย
  • การเชื่อมต่อ MSSQL (NOLOCK): คำสั่ง SQL ฝั่ง MSSQL มีการใส่ WITH (NOLOCK) เพื่อป้องกันไม่ให้คำสั่งอ่านข้อมูลไป Lock ตารางในระบบ ERP ใหญ่
