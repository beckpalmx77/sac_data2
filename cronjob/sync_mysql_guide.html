หากในอนาคตต้องการเพิ่มหรือลดฐานข้อมูลที่ต้องการ Sync สามารถแก้ไขได้ง่ายๆ ที่ไฟล์ sync_mysql.bat โดยทำตามขั้นตอนนี้:

  1. คลิกขวาที่ไฟล์ sync_mysql.bat แล้วเลือก Edit (แก้ไข) ด้วย Notepad หรือ Code Editor
  2. ค้นหาบรรทัดที่กำหนดตัวแปร set "DATABASES=..." (ประมาณบรรทัดที่ 26)
  3. เพิ่มชื่อฐานข้อมูลใหม่ต่อท้ายโดยเว้นวรรค 1 ช่อง เช่น:

  4. กดบันทึก (Save) ไฟล์ sync_mysql.bat
💡 ข้อดีของระบบลูปอัตโนมัติ:
เมื่อระบุชื่อฐานข้อมูลเพิ่มเข้าไปในตัวแปร DATABASES แล้ว ตัวสคริปต์จะทำการตรวจสอบ, สร้างฐานข้อมูลที่ปลายทางให้อัตโนมัติ (หากยังไม่มี), และสั่งดัมพ์สตรีมข้อมูลผ่าน Direct Pipe ให้ครบถ้วนทีละฐานข้อมูลทันที โดยไม่ต้องแก้ไขคำสั่งหรือตรรกะบรรทัดอื่นเลย

🚀 วิธีการใช้งานสคริปต์ sync_mysql.bat

ไฟล์สคริปต์ถูกสร้างไว้ที่: D:\wk_ai\repair_wamp_mysql\sync_mysql.bat

1เปิดใช้งานสคริปต์

ดับเบิ้ลคลิกไฟล์ sync_mysql.bat ได้ทันที หรือรันผ่าน Command Prompt:

REM รันแบบแสดงเมนูและทดสอบการเชื่อมต่อ D:\wk_ai\repair_wamp_mysql\sync_mysql.bat

2การเลือกโหมดการทำงานผ่านหน้าจอเมนู

ปุ่มกด ชื่อโหมด คำอธิบาย คำแนะนำ
กด 1 Direct Stream Sync ส่งข้อมูลจาก mysqldump เข้า mysql ปลายทางตรงๆ แบบ Pipe สตรีมผ่านเครือข่าย ไม่ต้องเขียนไฟล์ลงดิสก์ แนะนำ (เร็วที่สุด)
กด 2 Backup then Import ดัมพ์ไฟล์ .sql เก็บไว้ในโฟลเดอร์ backups\ ก่อน แล้วค่อยสั่ง Import เข้าปลายทาง ปลอดภัย (เก็บไฟล์สำรอง)
กด 3 Test Connection Only ทดสอบการเชื่อมต่อทั้งสองเครื่องและแสดงผล จากนั้นจบการทำงานโดยไม่มีการถ่ายโอนข้อมูล ตรวจสอบระบบ
กด 4 Exit ยกเลิกและปิดหน้าต่างทันที -

3การตั้งเวลาทำงานอัตโนมัติ (Windows Task Scheduler) ด้วย Option 1

เพื่อความสะดวกในการทำงานทุกวัน สคริปต์รองรับการทำงานแบบ Headless อัตโนมัติ (ไม่ถามยืนยัน ไม่ค้างหน้าต่าง) โดยเลือกโหมด 1 (Direct Stream Sync) เสมอผ่านพารามิเตอร์ --auto

⏰ สถานะปัจจุบัน: ได้สร้างและลงทะเบียน Task ชื่อ MySQL_Sync_Daily ไว้ใน Windows Task Scheduler แล้ว โดยมีกำหนดเวลาทำงานทุกวัน เวลา 02:00 น.

วิธีที่ 1: จัดการผ่านสคริปต์อัตโนมัติ (แนะนำ สะดวกที่สุด)

สามารถดับเบิ้ลคลิกไฟล์ create_task_schedule.bat เพื่อเปิดเมนูจัดการได้ทันที:

  • กด 1: เปลี่ยนเวลาตั้งเวลา เช่น 01:00, 02:30 หรือเวลาที่ต้องการ
  • กด 2: สั่งรัน Task ทันทีเพื่อทดสอบการทำงานเบื้องหลัง
  • กด 3: ตรวจสอบสถานะและเวลาที่จะรันรอบถัดไป (Next Run Time)
  • กด 4: ลบ Task ออกจากระบบเมื่อไม่ต้องการใช้งานแล้ว

วิธีที่ 2: ตั้งค่าหรือตรวจสอบด้วยตนเองผ่าน Task Scheduler GUI (taskschd.msc)

  1. กดปุ่มลัด Windows + R บนคีย์บอร์ด พิมพ์ taskschd.msc แล้วกด Enter เพื่อเปิดหน้าต่าง Task Scheduler
  2. ที่แถบซ้าย คลิกที่ Task Scheduler Library จะพบ Task ชื่อ MySQL_Sync_Daily
  3. หากต้องการสร้างหรือปรับแต่งเอง ให้ตรวจสอบค่าต่างๆ ดังนี้:
    แถบการตั้งค่า (Tab) หัวข้อ (Field) ค่าที่ต้องระบุ (Value)
    General Name MySQL_Sync_Daily
    Triggers Schedule Daily (ทุกวัน) กำหนดเวลาตามต้องการ เช่น 02:00:00
    Actions Action Start a program
    Program/script cmd.exe
    Add arguments /c D:\wk_ai\repair_wamp_mysql\sync_mysql_auto.bat
    Settings If the task fails... Restart every 10 minutes (ถ้าต้องการให้รันซ้ำเมื่อเน็ตหลุด)

วิธีที่ 3: คำสั่ง Command Prompt สำหรับตั้งค่าด้วยตนเอง

REM คำสั่งสร้าง Task Scheduler รันทุกวันเวลา 02:00 น. อัตโนมัติด้วย sync_mysql_auto.bat : schtasks /create /tn "MySQL_Sync_Daily" /tr "cmd.exe /c D:\wk_ai\repair_wamp_mysql\sync_mysql_auto.bat" /sc daily /st 02:00 /f

🛡️ พารามิเตอร์การดัมพ์ข้อมูลระดับ Production

สคริปต์ได้ติดตั้งคำสั่งและ Flag ป้องกันปัญหาคอขวดและป้องกันข้อมูลสูญหายไว้ครบถ้วน:

  • --single-transaction : ป้องกันการ Lock Table ของเอนจิน InnoDB ทำให้ระบบและเว็บต้นทางยังสามารถทำงาน อ่าน/เขียน ต่อเนื่องได้ตลอดระยะเวลา Sync
  • --quick : ทำการ Streaming ข้อมูลแถวต่อแถว ไม่โหลดทั้งตารางขึ้น Memory ป้องกัน RAM หมดหรือแฮงก์ระหว่างดัมพ์ไฟล์ขนาด 1.7 GB
  • --max_allowed_packet=512M : ขยายขนาด Buffer สูงสุด 512MB เพื่อรองรับข้อมูลก้อนใหญ่และฟิลด์ BLOB/TEXT โดยไม่เกิด Error Packet too large
  • --default-character-set=utf8mb4 : ป้องกันปัญหาวรรณยุกต์ ภาษาไทย และอีโมจิกลายเป็นเครื่องหมายคำถาม ???
  • --routines --triggers --events : นำเข้า Stored Procedures, Functions, Database Triggers และ Event Schedulers ทั้งหมดอย่างสมบูรณ์
  • --databases : สั่งสร้างฐานข้อมูลอัตโนมัติ (CREATE DATABASE IF NOT EXISTS) และเรียกใช้ USE `db` โดยอัตโนมัติ
