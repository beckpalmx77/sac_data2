รายละเอียดการ Export ข้อมูลเพื่อทำ Template Import Forecast

คู่มือและขั้นตอนการส่งออกไฟล์ข้อมูลยอดขายจาก ims_data_sale_sac_all เพื่อทำเป็น Template สำหรับนำเข้าแผนการขาย (Forecast Realtime)

ไปยังหน้าจอ Export Template กลับหน้า Forecast Realtime

สรุปการทำงานและโครงสร้างการกรองข้อมูล

ผู้ใช้งานสามารถเลือกส่งออกไฟล์ข้อมูลแผนการขายและยอดขายย้อนหลังผ่านหน้าจอ export_forecast_template.php โดยระบุตัวกรองเพียง 3 รายการหลัก ได้แก่ เดือน (Month), ปี (Year), และ พนักงานขาย (Sale Name) เพื่อนำไฟล์ Excel/CSV ที่ได้ไปกรอกเป้าแผนการขาย และนำเข้ากลับเข้าสู่ระบบที่หน้าจอ forecast_plan_display_realtime.php

ดึงรายชื่อเซลล์จาก: ims_data_sale_sac_all ยกเว้น: BTC, RQ, -, SACส่วนกลาง, READYQUICK ระบบ Auto-Sync สถิติยอดขายย้อนหลังจาก DB
ไฟล์ Template มาตรฐาน
รองรับไฟล์รูปแบบ .xlsx และ .csv (UTF-8 BOM) หน้าจอ Export Template plan_tires_r1.xlsx

ขั้นตอนการทำงาน 5 ขั้นตอน (5-Step End-to-End Process)

1
เลือกเงื่อนไข Export

เข้าหน้าจอ export_forecast_template.php แล้วเลือก **เดือน, ปี, และ พนักงานขาย**

2
Export ข้อมูลเป็น Excel

กดปุ่ม **Export Template** ระบบจะส่งออกไฟล์ข้อมูลลูกค้า SKU และประวัติยอดขายจาก ims_data_sale_sac_all

3
กรอกเป้า Forecast

เปิดไฟล์ Excel บนคอมพิวเตอร์ของคุณ แล้วทำการกรอก/แก้ไขคอลัมน์ **เป้า/แพลนยาง** (forecast_qty_month_1)

4
Import เข้าสู่ระบบ

กดปุ่ม **"นำเข้าข้อมูล Realtime Excel"** บนหน้าจอ Forecast Realtime เลือกเดือน/ปีเป้าหมาย แล้วอัปโหลดไฟล์กลับเข้าระบบ

5
Auto-Calculate & Sync

Backend จะดึงยอดขายจาก ims_data_sale_sac_all เพื่อคำนวณส่วนต่าง ค่าเฉลี่ย และ % ให้อัตโนมัติ

1. ตัวกรองการ Export (Filter Parameters)
ตัวกรอง (Filter) พารามิเตอร์ คำอธิบาย & แหล่งข้อมูล
เลือกเดือน month ระบุเดือนเป้าหมายการทำ Forecast (1 - 12)
เลือกปี year ระบุปี ค.ศ. เป้าหมาย เช่น 2026
พนักงานขาย sale_name ดึงรายชื่อพนักงานขายตรงจาก ims_data_sale_sac_all (เรียงตามตัวอักษร)
2. รายชื่อที่ถูกยกเว้น (Exclusion Rules)

ในตัวกรองพนักงานขาย ระบบจะทำการคัดออก (Exclude) รายชื่อที่เป็นบัญชีส่วนกลาง บัญชีสาขา หรือสัญลักษณ์ที่ไม่ใช่พนักงานขายเขตพื้นที่ ดังนี้:

BTC RQ - (ขีด) ส่วนกลาง READYQUICK READY QUICK
เงื่อนไข SQL
WHERE SALE_NAME IS NOT NULL AND TRIM(SALE_NAME) != '' AND TRIM(SALE_NAME) != '-' AND SALE_NAME NOT LIKE '%BTC%' AND SALE_NAME NOT LIKE '%RQ%' AND SALE_NAME NOT LIKE '%ส่วนกลาง%' AND SALE_NAME NOT LIKE '%READYQUICK%' AND SALE_NAME NOT LIKE '%READY QUICK%'
3. โครงสร้างคอลัมน์ Excel Template (Standard Column Mapping)

ไฟล์ Excel Template มาตรฐานที่ส่งออกและนำเข้า จะมีโครงสร้างคอลัมน์ตรงกับ plan_tires_r1.xlsx ดังนี้:

Index Col ชื่อคอลัมน์ใน Excel Field ฐานข้อมูล แหล่งข้อมูล / สูตรคำนวณ คำอธิบายการใช้งานในการ Import
0 A รหัสลูกค้า ar_code ims_data_sale_sac_all * จำเป็น ใช้จับคู่ข้อมูลลูกค้า

ข้อควรระวังในการเตรียมไฟล์ Import
  • รหัสลูกค้า (AR_CODE) และ รหัสสินค้า (SKU_CODE): ต้องถูกต้องตรงกับฐานข้อมูลหลัก หากระบุรหัสผิด ข้อมูลรายการนั้นอาจจะไม่ถูกบันทึก
  • แถวหัวข้อ (Row 1 Header): ห้ามลบหรือเปลี่ยนชื่อหัวข้อหลักภาษาไทย เพื่อให้ระบบ Dynamic Header Matching สามารถสแกนคอลัมน์ได้ถูกต้อง
  • รูปแบบไฟล์: บันทึกไฟล์เป็นนามสกุล .xlsx หรือ .csv (UTF-8)
คำแนะนำเพื่อความสะดวกรวดเร็ว
  • เทคนิคการกรอกข้อมูลอย่างเร็ว: ไม่จำเป็นต้องกรอกคอลัมน์สถิติต่างๆ ในคอลัมน์ J ถึง P ให้กรอกเฉพาะ **ยอดแพลนยาง (Col R)** เท่านั้น แล้วอัปโหลดได้เลย
  • การกรองก่อน Export: เลือก **เดือน, ปี, และพนักงานขาย** ที่หน้าจอ export_forecast_template.php ก่อนกด Export เพื่อให้ได้ไฟล์ Template ตรงกับที่ต้องการ
  • การนำเข้าซ้ำ (Update Existing): หากนำเข้าไฟล์เดิมซ้ำ ระบบจะทำการ อัปเดต (Update) ข้อมูลที่มีอยู่เดิมให้ทันทีโดยไม่เกิดข้อมูลซ้ำซ้อน
