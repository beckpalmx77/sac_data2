วิเคราะห์สาเหตุความล่าช้าเดิม (Root Causes Analysis)

1. ขาด Index ในตารางฐานข้อมูลขนาดใหญ่ (Critical Database Bottleneck)
ตาราง ims_data_sale_sac_all มีข้อมูล 532,830 แถว แต่ไม่มี Index บนฟิลด์ DI_REF และ AR_CODE ทำให้ทุกครั้งที่โปรแกรมสั่ง SELECT COUNT(*) ... WHERE DI_REF = ? หรือ UPDATE ... WHERE DI_REF = ? ระบบต้องทำการสแกนตารางแบบ Full Table Scan ทั้ง 5.3 แสนแถวซ้ำๆ 5,063 รอบ คิดเป็นสแกนข้อมูลกว่า 2,650 ล้านแถว!
2. วนลูปอ่านและอัปเดตทีละแถว (Row-by-Row Execution Overhead)
โค้ดเดิมใช้การวนลูป foreach แล้วสั่ง SELECT COUNT(*) เช็คว่ามีข้อมูลหรือไม่ ก่อนจะสั่ง UPDATE ทีละ 1 แถว ทำให้เกิดการส่งคำสั่ง SQL ไปยัง MySQL Server มากถึง 10,126 คำสั่ง ต่อการอัปโหลด 1 ครั้ง
3. คำสั่ง ซิงก์ข้อมูลแผนงาน (Sync Forecast Query) สแกนทั้งฐานข้อมูล
คำสั่งเดิมในส่วนการซิงก์ข้อมูลไปยังตาราง ims_tires_plan_forecast ทำการ GROUP BY AR_CODE บนตาราง ims_data_sale_sac_all ทั้งหมด 5.3 แสนแถวโดยไม่มีเงื่อนไขขอบเขต ทำให้เฉพาะขั้นตอนนี้กินเวลามากกว่า 30 วินาทีจนเกิด Metadata Lock

สรุปแนวทางแก้ไขและการออกแบบระบบใหม่ (Optimized Architecture)

  • สร้าง Database Indexing อัตโนมัติ: เพิ่ม Index idx_di_ref และ idx_ar_code ใน ims_data_sale_sac_all รวมถึง ims_tires_plan_forecast(ar_code) ช่วยให้การค้นหา/อัปเดตข้อมูลลดเวลาลงจาก 0.05 วินาที/แถว เหลือเพียง 0.0001 วินาที/แถว
  • In-Memory Deduplication (ยุบรายการซ้ำก่อนประมวลผล): นำรายการเลขที่เอกสาร DI_REF ซ้ำในไฟล์ Excel มาจัดกลุ่มในหน่วยความจำของ PHP เหลือเฉพาะรายการ Unique 5,052 เลขที่เอกสาร (ใช้เวลาเพียง 0.009 วินาที)
  • Temporary Table Bulk JOIN UPDATE Strategy: สร้างตารางชั่วคราว tmp_sale_import ใน MySQL แล้วใช้เทคนิค Bulk Insert ข้อมูลจาก Excel เข้าตารางชั่วคราวเป็นชุด (Chunk Batch 200 แถว) จากนั้นสั่ง UPDATE JOIN เพียงคำสั่งเดียว อัปเดตข้อมูลทั้ง 14,605 แถวในตารางจริงเสร็จสิ้นภายใน 0.64 วินาที!
  • Scoped Forecast Sync Query: ปรับแต่ง Query การซิงก์ข้อมูลพนักงานขาย/คนเทคเข้า ims_tires_plan_forecast ให้กรองเฉพาะรหัสลูกค้าที่ถูกอัปเดตในรอบปัจจุบันผ่าน WHERE seq_record = :seq_record ลดเวลาการซิงก์เหลือเพียง 0.08 วินาที
  • PhpSpreadsheet Light-Weight Reader: กำหนดตัวอ่านไฟล์ Excel ให้ใช้ $reader->setReadDataOnly(true) ข้ามการโหลด Styling และ รูปภาพ ทำให้โหลดไฟล์ Excel 5,063 แถวเสร็จใน 6.5 วินาที

ตัวอย่างซอร์สโค้ดหลักที่ปรับปรุง (Core Implementation)

// 1. สร้าง Index ป้องกันความล่าช้าในระดับฐานข้อมูล
$conn->exec("CREATE INDEX IF NOT EXISTS idx_di_ref ON ims_data_sale_sac_all (DI_REF)");
$conn->exec("CREATE INDEX IF NOT EXISTS idx_ar_code ON ims_data_sale_sac_all (AR_CODE)");

// 2. สร้างตารางชั่วคราวแบบ InnoDB เพื่อทำ Bulk Update
$conn->exec("CREATE TEMPORARY TABLE IF NOT EXISTS tmp_sale_import (
    DI_REF VARCHAR(100) PRIMARY KEY,
    AR_NAME VARCHAR(255),
    SALE_NAME VARCHAR(255),
    TAKE_NAME VARCHAR(255),
    TRD_AMPHUR VARCHAR(100),
    TRD_PROVINCE VARCHAR(100)
) ENGINE=InnoDB DEFAULT CHARSET=utf8;");

// 3. สั่ง JOIN UPDATE เพียงครั้งเดียวสำหรับทั้งไฟล์
$sql_update_all = "UPDATE ims_data_sale_sac_all t
                   INNER JOIN tmp_sale_import tmp ON t.DI_REF = tmp.DI_REF
                   SET 
                       t.AR_NAME = tmp.AR_NAME,
                       t.SALE_NAME = tmp.SALE_NAME,
                       t.TAKE_NAME = tmp.TAKE_NAME,
                       t.TRD_AMPHUR = tmp.TRD_AMPHUR,
                       t.TRD_PROVINCE = tmp.TRD_PROVINCE,
                       t.seq_record = :seq_record";
$stmt_upd = $conn->prepare($sql_update_all);
$stmt_upd->execute([':seq_record' => $seq_record]);

// 4. ซิงก์เฉพาะชุดข้อมูลที่เพิ่งอัปเดตไปยังแผนงาน Forecast
$sql_sync_forecast = "UPDATE ims_tires_plan_forecast p
                      INNER JOIN (
                          SELECT AR_CODE, MAX(SALE_NAME) AS SALE_NAME, MAX(TAKE_NAME) AS TAKE_NAME, MAX(TRD_AMPHUR) AS TRD_AMPHUR, MAX(TRD_PROVINCE) AS TRD_PROVINCE
                          FROM ims_data_sale_sac_all
                          WHERE seq_record = :seq_record
                          GROUP BY AR_CODE
                      ) s ON p.ar_code = s.AR_CODE
                      SET p.sale_name = s.SALE_NAME, p.take_name = s.TAKE_NAME, p.amphur = s.TRD_AMPHUR, p.province = s.TRD_PROVINCE";
$stmt_sync = $conn->prepare($sql_sync_forecast);
$stmt_sync->execute([':seq_record' => $seq_record]);
