2. 5 สถาปัตยกรรมหลักในการเพิ่มความเร็ว (Core Concepts)

1. Strategic Database Indexing

สร้าง Index ที่เจาะจงบนฟิลด์เงื่อนไข (DI_REF, AR_CODE, SKU_CODE) ช่วยเปลี่ยนการค้นหาจาก Full Table Scan 5.3 แสนแถว ให้เป็นการค้นหาแบบ B-Tree Lookup ทันที (< 0.001 วินาที)

2. In-Memory Deduplication

จัดกลุ่มและยุบข้อมูลที่ซ้ำกันในระดับหน่วยความจำ (RAM) ของ PHP ด้วย Associative Array ก่อนส่งไปฐานข้อมูล ช่วยลดจำนวนแถวที่ต้องประมวลผลลง 30-70% ในทันที

3. Bulk Temp Table & JOIN UPDATE

ย้ายจากการวนลูปส่งคำสั่ง SELECT/UPDATE ทีละแถว มาเป็นการสร้าง TEMPORARY TABLE (InnoDB) แล้ว Insert แบบ Chunk Batch (ทีละ 200 แถว) จากนั้นใช้ INNER JOIN UPDATE หรือ UPSERT เพียงคำสั่งเดียว

4. Scoped Target Syncing

ยกเลิกการ GROUP BY ตารางประวัติขายย้อนหลังทั้งหมด 5.3 แสนแถว แล้วเปลี่ยนเป็นการกรองเฉพาะลูกค้าที่เพิ่งถูกอัปเดตผ่าน WHERE seq_record = :seq_record

5. Stream Read Only Excel

เปิดใช้งาน setReadDataOnly(true) ใน PhpSpreadsheet เพื่อดึงเฉพาะค่าข้อมูลดิบ ตัดการโหลด Cell Styling, Borders, Colors และ รูปภาพออกทั้งหมด

3. ขั้นตอนการทำงานทางเทคนิค (Technical Step-by-Step Workflow)

1
รับไฟล์และตรวจสอบความถูกต้อง (File Upload & Pre-Check)
ตรวจสอบ MIME Type ของไฟล์ Excel (ต้องเป็น .xlsx หรือ .xls เท่านั้น) และย้ายไฟล์ไปยังโฟลเดอร์ปลายทาง uploads/
2
ตรวจสอบและสร้าง Database Index อัตโนมัติ (Auto Index Guarantee)
ระบบสั่งรันคำสั่ง CREATE INDEX IF NOT EXISTS เพื่อการันตีว่าตารางเป้าหมายจะมี Index บนคีย์หลักเสมอ ช่วยป้องกันปัญหาหากย้ายโค้ดไปรันบน Database Server เครื่องใหม่
3
สตรีมอ่านไฟล์แบบ Light-Weight (Read Data Only Stream)
ใช้ IOFactory::createReaderForFile() ร่วมกับ setReadDataOnly(true) เพื่ออ่านเฉพาะ Array ข้อมูลดิบ ข้าม Styling ทั้งหมด
4
จัดกลุ่มและยุบข้อมูลซ้ำในแรม (In-Memory Deduplication)
วนลูป foreach อ่านข้อมูลลง Associative Array โดยใช้ Primary Key (เช่น DI_REF หรือ SKU_CODE) เป็น Key เพื่อให้เหลือเฉพาะค่าล่าสุดที่ไม่ซ้ำกัน
5
สร้าง Temporary Table และ Bulk Chunk Insert
สร้าง CREATE TEMPORARY TABLE tmp_import (...) ENGINE=InnoDB และ Insert ข้อมูลแบบ Multi-row VALUES ทีละ 200 แถวลงในแรม/เซสชันชั่วคราว
6
รันคำสั่ง Bulk UPDATE JOIN / UPSERT สั่งงานครั้งเดียว
สั่ง UPDATE ims_target t INNER JOIN tmp_import tmp ON ... SET ... เพื่อให้อัปเดตตารางหลัก 10,000+ แถวเสร็จสิ้นใน 0.5 วินาที
7
ซิงก์ข้อมูลไปยังตารางที่เกี่ยวข้อง (Scoped Relation Sync)
รันคำสั่งซิงก์ข้อมูลอ้างอิงไปยังตารางอื่น (เช่น ims_tires_plan_forecast หรือ ims_data_sale_sac_all) โดยกรองเฉพาะขอบเขตของ Batch ปัจจุบัน
8
บันทึก Log และส่งตอบกลับรูปแบบ JSON
บันทึกประวัติลงตาราง log_import_data และส่งผลลัพธ์ json_encode กลับไปยังหน้าหน้าต่าง SweetAlert2 เพื่อแสดงหลอด Progress Bar และเวลาที่ใช้

4. แม่แบบโค้ดมาตรฐานสำหรับนำไปใช้งาน (Standard Code Templates)

1. โค้ดส่วนประมวลผลฝั่งเซิร์ฟเวอร์ (Backend PHP Process Template):

<?php
session_start();
error_reporting(0);

include '../config/connect_db.php';
require '../vendor/autoload.php';

use PhpOffice\PhpSpreadsheet\IOFactory;

if (isset($_FILES['excelFile']['name']) && $_FILES['excelFile']['error'] == UPLOAD_ERR_OK) {
    $file_Upload = $_FILES['excelFile']['name'];
    $fileTmp = $_FILES['excelFile']['tmp_name'];
    $uploadFile = '../uploads/' . basename($file_Upload);

    if (move_uploaded_file($fileTmp, $uploadFile)) {
        try {
            // 1. ประกัน Index สำหรับตารางฐานข้อมูล
            try { $conn->exec("CREATE INDEX idx_key_name ON target_table_name (KEY_COLUMN)"); } catch (Exception $e) {}

            // 2. อ่านไฟล์แบบ Read Data Only
            $reader = IOFactory::createReaderForFile($uploadFile);
            $reader->setReadDataOnly(true);
            $spreadsheet = $reader->load($uploadFile);
            $rows = $spreadsheet->getActiveSheet()->toArray();

            $seq_record = md5(rand());
            $dataByKey = [];
            $totalRows = 0;

            // 3. Deduplicate ในแรม
            foreach ($rows as $index => $row) {
                if ($index == 0) continue; // ข้าม Header
                $KEY = isset($row[0]) ? trim($row[0]) : "";
                if ($KEY === "") continue;

                $totalRows++;
                $dataByKey[$KEY] = [
                    'FIELD1' => isset($row[1]) ? trim($row[1]) : "",
                    'FIELD2' => isset($row[2]) ? trim($row[2]) : ""
                ];
            }

            // 4. สร้าง Temporary Table
            $conn->exec("CREATE TEMPORARY TABLE IF NOT EXISTS tmp_import (
                KEY_COLUMN VARCHAR(100) PRIMARY KEY,
                FIELD1 VARCHAR(255),
                FIELD2 VARCHAR(255)
            ) ENGINE=InnoDB DEFAULT CHARSET=utf8;");
            $conn->exec("TRUNCATE TABLE tmp_import;");

            // 5. Multi-Row Chunk Insert (ทีละ 200 แถว)
            $chunk = [];
            foreach ($dataByKey as $key => $d) {
                $chunk[] = [$key, $d['FIELD1'], $d['FIELD2']];
                if (count($chunk) >= 200) {
                    insertChunkData($conn, $chunk);
                    $chunk = [];
                }
            }
            if (!empty($chunk)) insertChunkData($conn, $chunk);

            // 6. Single JOIN UPDATE / UPSERT
            $sql_update = "UPDATE target_table_name t
                           INNER JOIN tmp_import tmp ON t.KEY_COLUMN = tmp.KEY_COLUMN
                           SET t.FIELD1 = tmp.FIELD1, t.FIELD2 = tmp.FIELD2, t.seq_record = :seq_record";
            $stmt_upd = $conn->prepare($sql_update);
            $stmt_upd->execute([':seq_record' => $seq_record]);
            $updatedRows = $stmt_upd->rowCount();

            // 7. ส่งตอบกลับ JSON
            header('Content-Type: application/json; charset=utf-8');
            echo json_encode([
                'success' => true,
                'file_name' => $file_Upload,
                'count' => $totalRows,
                'updated' => $updatedRows
            ]);

        } catch (Exception $e) {
            header('Content-Type: application/json; charset=utf-8');
            echo json_encode(['success' => false, 'message' => $e->getMessage()]);
        }
    }
}

function insertChunkData($conn, $data) {
    $placeholders = [];
    $values = [];
    foreach ($data as $r) {
        $placeholders[] = "(?, ?, ?)";
        array_push($values, $r[0], $r[1], $r[2]);
    }
    $sql = "INSERT INTO tmp_import (KEY_COLUMN, FIELD1, FIELD2) VALUES " . implode(", ", $placeholders);
    $stmt = $conn->prepare($sql);
    $stmt->execute($values);
}

$('#uploadForm').on('submit', function (e) {
    e.preventDefault();
    let formData = new FormData(this);
    let startTime = new Date();

            </div>
        `,
        allowOutsideClick: false,
        showConfirmButton: false,
        didOpen: () => { Swal.showLoading(); }
    });

    // จำลองหลอดวิเศษแสดงความก้าวหน้า
    let progressWidth = 0;
    let progressInterval = setInterval(function() {
        progressWidth = Math.min(progressWidth + 15, 95);
        $('#swalProgressBar').css('width', progressWidth + '%').text(progressWidth + '%');
    }, 150);

    $.ajax({
        url: 'import_process/your_process_script.php',
        type: 'POST',
        data: formData,
        contentType: false,
        processData: false,
        dataType: 'json',
        success: function (response) {
            clearInterval(progressInterval);
            let duration = ((new Date() - startTime) / 1000).toFixed(2);

            if (response.success) {
                $('#swalProgressBar').css('width', '100%').removeClass('bg-primary').addClass('bg-success').text('100%');
                
                Swal.fire({
                    icon: 'success',
                    title: 'นำเข้าข้อมูลสำเร็จ',

                        <div class="text-start small p-3 bg-light border rounded mb-3">
                            <p class="mb-1"><strong>ไฟล์:</strong> ${response.file_name}</p>
                            <p class="mb-1"><strong>จำนวนรายการ:</strong> ${response.count.toLocaleString()} รายการ</p>
                            <p class="mb-1"><strong>อัปเดตสำเร็จ:</strong> ${response.updated.toLocaleString()} รายการ</p>
                            <p class="mb-0"><strong>เวลาที่ใช้:</strong> ${duration} วินาที</p>
                        </div>
                    `,
                    confirmButtonText: 'รีเฟรชทันที'
                }).then(() => { location.reload(); });
            } else {
                Swal.fire('เกิดข้อผิดพลาด', response.message, 'error');
            }
        }
    });
});

5. ข้อควรระวังและแนวปฏิบัติที่ดี (Best Practices Checklist)

Checklist 6 ข้อสำคัญในการสร้างหน้าจอ Import ใหม่:
  1. เช็ค Index เสมอ: ฟิลด์ที่นำมาใช้ในเงื่อนไข WHERE หรือ ON JOIN ต้องได้รับการสร้าง Index ในฐานข้อมูลเสมอ
  2. หลีกเลี่ยงการวนลูป Query: ห้ามใช้ SELECT หรือ UPDATE ทีละแถวในวนลูป foreach เป็นอันขาด
  3. ใช้ Temporary Table บน InnoDB: ตั้งค่า ENGINE=InnoDB DEFAULT CHARSET=utf8 ป้องกันปัญหาหน่วยความจำและข้อจำกัดความยาวของ String
  4. สตรีมเฉพาะ Data ดิบ: ตั้งค่า setReadDataOnly(true) ทุกครั้งที่อ่านไฟล์ Excel
  5. จำกัดขอบเขตการซิงก์: กรองข้อมูลด้วย seq_record หรือ PRIMARY KEY ของ Batch ปัจจุบัน ไม่ซิงก์ข้อมูลทั้งตารางย้อนหลัง
  6. ตอบกลับด้วย JSON: ส่งข้อมูลผลลัพธ์ในรูปแบบ JSON และใช้ SweetAlert2 แสดงผลลัพธ์อย่างสวยงาม ชัดเจน
