2. เงื่อนไขสำคัญในการนำเข้า

  • ข้อมูลซ้ำ (Duplicate Check): ระบบใช้ Month + Year + AR_CODE + SKU_CODE + SALE_NAME เป็น Key ในการตรวจสอบ หากพบข้อมูลเดิมระบบจะทำการ UPDATE ตัวเลขเป้ารายเดือน (คอลัมน์ Q) และตัวเลขคาดการณ์/แพลนยาง (คอลัมน์ R) ด้วยค่าใหม่จากไฟล์ Excel ทันที (รองรับกรณีไม่ได้ป้อนตัวเลขตอนแรก แล้วทำการนำเข้าอัปเดตภายหลัง) พร้อมคำนวณส่วนต่างและ % เปรียบเทียบให้อัตโนมัติ โดยคงค่าประวัติยอดขายเดิมไว้
  • การจัดการสูตร (#REF!): ระบบรองรับไฟล์ที่มีสูตรติดมา หากพบ error #REF! ระบบจะพยายามดึงค่าล่าสุดที่คำนวณไว้มาใช้แทน
  • ค่าว่าง: หากแถวใดไม่มีทั้ง AR_CODE และ SKU_CODE ระบบจะข้ามแถวนั้นไป
  • ระบบ Caching: หลังนำเข้าเสร็จ ค่า load_time จะถูกตั้งเป็น 0 เพื่อให้หน้าจอ Interactive ทำการดึงยอดขายจริงมา Update ให้อัตโนมัติเมื่อมีการเปิดดูครั้งแรก

3. ระบบการดึงยอดขายจริงอัตโนมัติ (Auto-Sync Sales Data)

เพื่อลดภาระในการจัดเตรียมไฟล์ และความถูกต้องของข้อมูล ระบบได้ออกแบบให้มีการดึงยอดขายจริงจากฐานข้อมูลให้อัตโนมัติ:

  • ประหยัดเวลา: ผู้ใช้งาน ไม่จำเป็น ต้องกรอกยอดขายย้อนหลัง (M-1, M-2, M-3) ในไฟล์ Excel สามารถปล่อยเป็นค่าว่างหรือ 0 ได้
  • การทำงาน: เมื่อมีการนำเข้าไฟล์ใหม่ หรือเปิดดูข้อมูลเดือน/ปี นั้นเป็นครั้งแรก ระบบจะตรวจพบว่ายังไม่มีการเชื่อมโยงข้อมูล และจะทำการดึงยอดขายจริงจากตาราง ims_data_sale_sac_all มาบันทึกลงในแผนให้ทันที
  • ความแม่นยำ: ข้อมูลที่ดึงมาจะรวมถึงยอดขายย้อนหลัง 3 เดือน และค่าเฉลี่ยรายเดือนของปีที่ผ่านมา
  • การปรับปรุงข้อมูล: หากมีการขายเกิดขึ้นหลังจากนำเข้าไฟล์ไปแล้ว ผู้ใช้สามารถกดปุ่ม ที่หน้าจอหลักเพื่อดึงข้อมูลล่าสุดได้ทุกเมื่อ

4. ขั้นตอนการ Upload

  1. เข้าที่หน้าจอ "นำเข้าข้อมูล Tires Plan Forecast"
  2. เลือก เดือน และ ปี ที่ต้องการนำเข้าข้อมูล
  3. คลิกที่พื้นที่อัปโหลดเพื่อเลือกไฟล์ Excel จากเครื่อง
  4. กดปุ่ม "เริ่มนำเข้าข้อมูล" และรอจนกว่าแถบความเคลื่อนไหวจะเต็ม
  5. เมื่อเสร็จสิ้น ระบบจะพาไปยังหน้าจอตรวจสอบข้อมูล (Interactive) เพื่อดูผลลัพธ์
