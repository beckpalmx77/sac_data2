1. โครงสร้างไฟล์ Excel (Column Mapping)

การจัดคอลัมน์ในแผ่นงาน Excel อ้างอิงตามไฟล์ plan_tires_r1.xlsx (21 คอลัมน์ A ถึง U โดย Row 1 เป็นหัวคอลัมน์ และข้อมูลจริงเริ่มต้นที่ แถวที่ 2 เป็นต้นไป):

คอลัมน์ (Index) หัวข้อคอลัมน์ใน Excel ชื่อฟิลด์ในระบบ คำอธิบาย / รายละเอียดเพิ่มเติม
A (1)รหัสลูกค้าar_codeจำเป็น รหัสร้านค้า (เช่น SAC.0000006)
B (2)รายชื่อลูกค้าar_nameชื่อลูกค้า / ร้านค้า
C (3)เซลล์sale_nameจำเป็น ชื่อพนักงานขาย
D (4)เทคtake_nameชื่อพนักงานเทคที่ดูแล
E (5)อำเภอamphurอำเภอของที่อยู่ลูกค้า
F (6)จังหวัดprovinceจังหวัดของที่อยู่ลูกค้า
G (7)ยี่ห้อbrand_codeยี่ห้อของยางรถยนต์ (เช่น LEAO, LLIT, BS, FS)
H (8)รหัสสินค้า 1sku_codeจำเป็น รหัสสินค้า / SKU (เช่น LE2055516-LISP/HP3)
I (9)รายละเอียดsku_nameรายละเอียด / ชื่อสินค้า SKU
J (10)เฉลี่ย 12 เดือน ปีก่อนavg_per_month_yearคำนวณให้อัตโนมัติ ยอดขายเฉลี่ยรายเดือนของปีก่อนหน้า
K (11)ยอดขายสูงสุดต่อเดือน(ปีก่อน)max_qty_yearคำนวณให้อัตโนมัติ ยอดขายสูงสุดต่อเดือนในปีก่อนหน้า
L (12)ยอดขายต่ำสุดต่อเดือน(ปีก่อน)min_qty_yearคำนวณให้อัตโนมัติ ยอดขายต่ำสุดต่อเดือนในปีก่อนหน้า
M (13)[เดือน-ปี ย้อนหลัง M-3] (เช่น เมษายน'26)sales_month_3ดึงให้อัตโนมัติ ยอดขายจริงย้อนหลัง 3 เดือน (M-3)
N (14)[เดือน-ปี ย้อนหลัง M-2] (เช่น พฤษภาคม'26)sales_month_2ดึงให้อัตโนมัติ ยอดขายจริงย้อนหลัง 2 เดือน (M-2)
O (15)[เดือน-ปี ย้อนหลัง M-1] (เช่น มิถุนายน'26)sales_month_1ดึงให้อัตโนมัติ ยอดขายจริงย้อนหลัง 1 เดือน (M-1)
P (16)ค่าเฉลี่ย 3 เดือนavg_3_monthคำนวณให้อัตโนมัติ ค่าเฉลี่ยยอดขายย้อนหลัง 3 เดือน
Q (17)เป้ารายเดือนtarget_qty_monthเป้าหมายประจำเดือน
R (18)แพลนยางเดือนที่ต้องการforecast_qty_month_1จำเป็น จำนวนยางที่คาดการณ์/วางแผนจะขาย (ข้อมูลที่คุณระบุใส่ใน Excel)
S (19)เทียบ แพลนยาง ลบ ค่าเฉลี่ยcompare_forecast_month_1คำนวณให้อัตโนมัติ ส่วนต่างของแผนและค่าเฉลี่ยย้อนหลัง (สูตร: =R2-P2)
T (20)เทียบ แพลนยาง ลบ ค่าเฉลี่ย %compare_sales_percentคำนวณให้อัตโนมัติ อัตราส่วนเปรียบเทียบ (สูตร: =IFERROR(R2/P2,0) เช่น ค่าในแผ่นงานเป็น 2 หมายถึง 200%)
U (21)ผู้รับผิดชอบresponsible_personชื่อผู้รับผิดชอบ / ผู้ดูแลร้านค้า (Optional)

2. เงื่อนไขและกฎเกณฑ์การคำนวณในระบบ

  • การอัปเดตเมื่อพบข้อมูลซ้ำ (Update Duplicate Records): หากนำเข้าไฟล์ Excel แล้วพบรายการเดิมซ้ำในเดือน/ปีเดียวกัน (พิจารณาจาก รหัสลูกค้า + รหัสสินค้า + พนักงานขาย) ระบบจะทำการ UPDATE ตัวเลขใหม่ลงใน Column Q (เป้ารายเดือน) และ Column R (แพลนยาง) ด้วยค่าล่าสุดจากไฟล์ Excel ทันที (รองรับกรณีที่ไม่ได้ป้อนตัวเลขใน Excel ในตอนแรก แล้วทำการนำเข้าไฟล์เพื่อมาอัปเดตภายหลัง) พร้อมคำนวณ Column S (ส่วนต่าง) และ Column T (% ต่าง) ใหม่ให้อัตโนมัติ โดยยังคงรักษาประวัติยอดขายเดิมในฐานข้อมูลไว้ไม่ให้สูญหาย
  • คอลัมน์สถิติต่างๆ (คอลัมน์ J ถึง P): คอลัมน์สถิติย้อนหลัง ได้แก่ เฉลี่ยต่อเดือนปีที่แล้ว (J), ยอดขายสูงสุด/ต่ำสุด (K-L), ยอดขายย้อนหลัง M-3, M-2, M-1 (M-O) และค่าเฉลี่ย 3 เดือน (P) ไม่จำเป็นต้องใส่ค่าในไฟล์ Excel เนื่องจากเมื่อทำการนำเข้า (Import) ระบบจะดึงยอดขายจากฐานข้อมูลและคำนวณค่าสถิติต่างๆ ให้อัตโนมัติ
  • การแยกตารางเก็บข้อมูลอย่างอิสระ: ข้อมูลเรียลไทม์ทั้งหมดจะถูกแยกไปบันทึกยังตารางฐานข้อมูลชุดใหม่ ims_tires_plan_forecast_realtime โดยสมบูรณ์ ไม่ปะปนกับตาราง Interactive เดิม
  • การคำนวณคอลัมน์ใหม่ (เพิ่มเติมจาก Excel): ในตารางหลักบนหน้าจอจะมีคอลัมน์ "ยอดขายจริง" (ดึงสะสมจากฐานข้อมูลตามเดือน/ปีที่คาดการณ์) และคอลัมน์ "ขาด/เกิน" (คำนวณจากสูตร: ยอดขายจริง - แพลนยาง) โดยคอลัมน์พิเศษทั้ง 2 นี้ระบบจะคำนวณให้อัตโนมัติ โดยไม่จำเป็นต้องมีในไฟล์นำเข้า Excel (Template)
  • การคำนวณเปอร์เซ็นต์แบบ Realtime: ค่าเทียบยอดขาย % (คอลัมน์ T) ในสคริปต์ JavaScript และระบบประมวลผล จะคำนวณตรงตามสูตรของไฟล์ Excel คือ คาดการณ์ / เฉลี่ย 3 เดือน * 100 (เช่น ค่าเฉลี่ย 3 เดือนเป็น 4 และคาดการณ์เป็น 8 เปอร์เซ็นต์ที่คำนวณได้บนจอคือ 200%)
  • ป้องกันการ Sync ทับข้อมูลใน Excel (load_time = 1): ระบบได้ตั้งค่าสถานะนำเข้าเป็น 1 ทันที เพื่อป้องกันไม่ให้สคริปต์อัปเดตอัตโนมัติบนหน้าเว็บเข้าไปดึงยอดขายจริงจากฐานข้อมูลระบบมาเขียนทับตัวเลขสถิติยอดขายที่ผู้ใช้นำเข้ามาจากไฟล์ Excel
  • ข้ามแถวว่างอัตโนมัติ: แถวใดในไฟล์ Excel ที่ไม่มี รหัสลูกค้า, รหัสสินค้า หรือ เซลล์ ระบบจะทำการข้ามการนำเข้าสำหรับแถวนั้นทันที

3. ขั้นตอนการนำเข้าไฟล์ Excel บนหน้าจอ

  1. เปิดไปที่หน้าจอ Tires Plan (Realtime Excel)
  2. ที่เมนูด้านขวาบน ให้คลิกปุ่ม "นำเข้าข้อมูล Realtime Excel" เพื่อเปิดหน้าต่างอัปโหลด
  3. ในหน้าต่างดาวน์โหลด ให้เลือก เดือน และ ปี ที่ตรงกับข้อมูลในไฟล์ Excel ที่นำเข้า
  4. ลากไฟล์ Excel plan_tires_r1.xlsx มาวางในกรอบอัปโหลด หรือคลิกเพื่อเลือกไฟล์จากคอมพิวเตอร์ของคุณ
  5. คลิกปุ่ม "เริ่มนำเข้าข้อมูล" ระบบจะอัปโหลดและแสดงสถานะประมวลผล เมื่อเสร็จสมบูรณ์ระบบจะปิดหน้าต่างลงและโหลดข้อมูลใหม่ขึ้นแสดงผลบนตารางหลักในทันที
