ขั้นตอนและกลไกการบันทึกข้อมูล (Save Process)

ระบบบันทึกข้อมูลในหน้าจอ forecast_plan_display_new.php ถูกออกแบบมาให้ทำงานแบบ "Batch Update" เพื่อความรวดเร็วและลดจำนวนครั้งในการติดต่อกับ Server โดยมีรายละเอียดดังนี้:

1. ข้อมูลที่ถูกบันทึก (What is saved?)

เมื่อกดปุ่ม "บันทึกการแก้ไขทั้งหมด" ระบบจะรวบรวมข้อมูลจาก ทุกแถวที่แสดงผลอยู่ในหน้าปัจจุบัน โดยบันทึกฟิลด์ดังต่อไปนี้:

ฟิลด์ข้อมูล คำอธิบาย
target_qty_month เป้าหมายการขายที่ผู้ใช้แก้ไขในช่อง Input
forecast_qty_month_1 ยอดคาดการณ์ที่ผู้ใช้แก้ไขในช่อง Input
compare_forecast_month_1 ส่วนต่างระหว่าง "ยอดคาดการณ์" เทียบกับ "ค่าเฉลี่ย 3 เดือน" (คำนวณให้อัตโนมัติ)
compare_sales_percent เปอร์เซ็นต์ส่วนต่างเทียบยอดขาย (คำนวณให้อัตโนมัติ)
remark หมายเหตุเพิ่มเติมที่พนักงานขายกรอก

2. ลำดับขั้นตอนการทำงาน (Workflow)

ขั้นตอนที่ 1: การรวบรวมข้อมูล (Client-side Data Gathering)

JavaScript จะทำการวนลูป (Iterate) ผ่านแถวของ DataTable เพื่อดึงค่าจาก input และดึง data-id ของแต่ละแถวมาเก็บไว้ในตัวแปรแบบ Array ในรูปแบบ JSON

ขั้นตอนที่ 2: การคำนวณแบบ Real-time (Auto Calculation)

ในขณะที่ผู้ใช้พิมพ์ตัวเลข ระบบจะมีฟังก์ชัน calculateRow() ทำงานเบื้องหลังเพื่อคำนวณส่วนต่างและ % ทันที และจะนำค่าที่คำนวณได้นี้ส่งไปบันทึกด้วย เพื่อให้ข้อมูลใน Database ตรงกับสิ่งที่ผู้เห็นบนหน้าจอ

ขั้นตอนที่ 3: การส่งข้อมูล (Ajax Transmission)

ข้อมูลทั้งหมดจะถูกส่งไปยังไฟล์ forecast_update_plan_new.php ผ่าน Ajax (POST Method) พร้อมการแสดงสถานะ Loading ด้วย SweetAlert2

ขั้นตอนที่ 4: การประมวลผลที่ Backend (Server-side Processing)
  • ตรวจสอบสิทธิการเข้าถึง (Session Check)
  • ใช้ Database Transaction (Begin Transaction) เพื่อรับประกันว่าข้อมูลทุกแถวต้องบันทึกสำเร็จทั้งหมด หากมีแถวใดผิดพลาดจะทำการ Rollback ทันที
  • วนลูป Execute คำสั่ง UPDATE ตาม ID ที่ได้รับมา
  • อัปเดตฟิลด์ import_date เป็นเวลาปัจจุบัน เพื่อให้ทราบว่าข้อมูลถูกแก้ไขล่าสุดเมื่อใด

3. ข้อควรระวัง

  • การบันทึกจะบันทึกเฉพาะ ข้อมูลที่แสดงอยู่ในหน้านั้นๆ (Page current) เท่านั้น
  • หากมีการแก้ไขข้อมูลแล้ว ห้ามกด Refresh หน้าจอ หรือเปลี่ยนหน้า DataTable ก่อนกดปุ่มบันทึก มิฉะนั้นสิ่งที่แก้ไขไว้จะหายไป
  • ระบบรองรับการกรอกตัวเลขที่มีเครื่องหมาย Comma (,) โดยจะทำการลบออกให้อัตโนมัติก่อนส่งไปคำนวณที่ Database
