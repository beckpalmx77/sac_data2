สรุปวิธีการคำนวณและเปรียบเทียบตรรกะ

จากการตรวจสอบไฟล์ forecast_plan_display_new.php และ forecast_sales_report_detail.php พบว่าขั้นตอนการคำนวณส่วนใหญ่มีความ เหมือนกัน แต่มีความแตกต่างเล็กน้อยในด้านการแสดงผลและการจัดการตัวเลขทศนิยม ดังนี้:

1. รายละเอียดการคำนวณแต่ละค่า

1. เฉลี่ย 12 ด. (Avg 12 Months)

คำนวณจากยอดขายรวมในปีที่แล้ว (ปีปัจจุบัน - 1) หารด้วย 12

ยอดขายรวมปีที่แล้ว / 12
2. MAX / MIN

ดึงค่าสูงสุด (MAX) และค่าต่ำสุด (MIN) จากยอดขายรายเดือนในปีที่แล้ว

3. ยอดขายย้อนหลัง (M-1, M-2, M-3)

ดึงยอดขายจริงจากฐานข้อมูลรายเดือนย้อนหลังจากเดือนที่เลือก

  • M-1: เดือนก่อนหน้าที่เลือก 1 เดือน
  • M-2: เดือนก่อนหน้าที่เลือก 2 เดือน
  • M-3: เดือนก่อนหน้าที่เลือก 3 เดือน
4. เฉลี่ย 3 ด. (Avg 3 Months) มีความต่างเล็กน้อย

คำนวณจากค่าเฉลี่ยของยอดขาย 3 เดือนย้อนหลัง

(M-1 + M-2 + M-3) / 3

ความต่าง:
- forecast_sales_report_detail.php: ใช้ฟังก์ชันปัดเศษแบบ 0.5 ขึ้นไป (Round Half Up)
- forecast_plan_display_new.php: ใช้การแสดงผลแบบไม่มีทศนิยม (number_format)

5. เทียบวางแผนการขาย (Quantity Difference) เหมือนกัน

คำนวณผลต่างระหว่างยอดที่วางแผนการขายกับค่าเฉลี่ย 3 เดือน

วางแผนการขาย - เฉลี่ย 3 เดือน
6. เทียบยอดขาย% (Percentage Difference) เหมือนกัน

คำนวณสัดส่วนการเปลี่ยนแปลงเป็นเปอร์เซ็นต์

((วางแผนการขาย - เฉลี่ย 3 เดือน) / เฉลี่ย 3 เดือน) * 100

หมายเหตุ: หากค่าเฉลี่ย 3 เดือนเป็น 0 ระบบจะกำหนดให้เป็น 0% เพื่อป้องกันการหารด้วยศูนย์ (Division by Zero)

2. ตารางเปรียบเทียบ logic ระหว่าง 2 หน้าจอ

รายการ forecast_plan_display_new.php forecast_sales_report_detail.php สถานะ
สูตรหาค่าเฉลี่ย 3 เดือน (M1+M2+M3) / 3 (M1+M2+M3) / 3 เหมือนกัน
การปัดเศษค่าเฉลี่ย ใช้ number_format(..., 0) มีฟังก์ชันเฉพาะ (>= 0.5 ปัดขึ้น) ต่างกันเล็กน้อย
สูตรหาผลต่าง (Compare 1) Forecast - Avg 3M Forecast - Avg 3M เหมือนกัน
สูตรหา % (Compare 2) (Diff / Avg 3M) * 100 (Diff / Avg 3M) * 100 เหมือนกัน
การคำนวณอัตโนมัติ (JS) คำนวณทันทีเมื่อแก้เลขวางแผนการขาย คำนวณทันทีเมื่อแก้เลขวางแผนการขาย เหมือนกัน
ข้อสรุป: ทั้งสองหน้าจอใช้ตรรกะทางคณิตศาสตร์แบบเดียวกันในการหาค่าวางแผนการขายและการเปรียบเทียบ แต่อาจพบตัวเลขต่างกันเพียง 1 หน่วยในบางกรณีเนื่องจากวิธีการปัดเศษที่ต่างกันในระดับ Code (PHP vs JS formatting)
