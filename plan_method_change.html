แผนการปรับปรุงหน้าจอ forecast_plan_display.php ให้เป็นแบบ Interactive

แนวทางนี้คือการเปลี่ยนหน้าจอแสดงผล "Tires Plan" จากเดิมที่เป็นแบบ อ่านอย่างเดียว (Read-only) ให้สามารถ แก้ไขและคำนวณผลลัพธ์ได้ทันที (Interactive) โดยยังคงใช้ข้อมูลพื้นฐานจากการ Import ไฟล์ Excel เช่นเดิม

1. การปรับปรุงส่วนการแสดงผล (Frontend UI)

  • เปลี่ยนคอลัมน์เป็น Input: เปลี่ยนการแสดงผลในคอลัมน์ เป้าหมาย (Target), คาดการณ์ (Forecast) และ หมายเหตุ (Remark) ให้เป็นกล่องข้อความ <input>
  • เพิ่มปุ่มบันทึก: เพิ่มปุ่ม "บันทึกข้อมูล" (Save Changes) ไว้ที่ส่วนหัวของตาราง (Card Header)
  • CSS Styling: ปรับแต่ง Input ให้มีขนาดพอดีกับตาราง และจัดตัวเลขให้ชิดขวา (text-end)

2. ระบบคำนวณอัตโนมัติ (Real-time Calculation)

ใช้ JavaScript (jQuery) เพื่อดึง Logic มาจากหน้า Sales Report:

  • Event Listener: เมื่อมีการพิมพ์ตัวเลขในช่อง "คาดการณ์ยอดขาย"
  • Formula 1 (Difference): ผลต่าง = ยอดคาดการณ์ - ค่าเฉลี่ย 3 เดือน
  • Formula 2 (Percentage): % ต่าง = (ผลต่าง / ค่าเฉลี่ย 3 เดือน) * 100
  • Instant Update: แสดงผลลัพธ์ในคอลัมน์ "เทียบคาดการณ์" และ "% เทียบยอดขาย" ทันทีโดยไม่ต้อง Refresh หน้าจอ

3. การจัดการข้อมูลฝั่งเซิร์ฟเวอร์ (Backend & Database)

  • AJAX Update: เมื่อกดปุ่มบันทึก ระบบจะส่งชุดข้อมูล (Array of Objects) ไปยังไฟล์ PHP ใหม่ (เช่น forecast_update_plan_data.php)
  • Batch Update: ใช้คำสั่ง UPDATE ims_tires_plan_forecast โดยระบุ ID ของแต่ละแถว เพื่อบันทึกค่าที่แก้ไขลงฐานข้อมูล
  • Data Consistency: ข้อมูลที่ถูกแก้ไขจะยังคงอยู่ในตารางเดิม (ims_tires_plan_forecast) ทำให้การดึงข้อมูลครั้งต่อไปเป็นค่าที่แก้ไขล่าสุด

4. ขั้นตอนการดำเนินการ (Action Plan)

  1. แก้ไข forecast_plan_fetch.php: ให้ส่ง HTML <input> กลับมาใน JSON แทนข้อความปกติ
  2. แก้ไข forecast_plan_display.php: เพิ่ม Script การคำนวณอัตโนมัติและปุ่มบันทึก
  3. สร้าง forecast_update_plan_data.php: เพื่อรับค่าจากการแก้ไขและ Update ลง Database
  4. ทดสอบการคำนวณและการบันทึกข้อมูล (Validation)
ข้อดีของแนวทางนี้: ช่วยให้ทีมงานสามารถ "ปรับจูน" ตัวเลขเป้าหมายหรือยอดคาดการณ์ที่นำเข้ามาจาก Excel ได้ทันทีผ่านหน้าเว็บ โดยไม่ต้องกลับไปแก้ไขในไฟล์ Excel แล้วนำเข้าใหม่ทุกครั้ง
