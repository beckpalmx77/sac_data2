เปรียบเทียบวิธีการจัดการข้อมูล: Tires Plan vs. Sales Report

1. วิธีการดึงข้อมูล (Data Sourcing)

หัวข้อ forecast_plan_display.php (Tires Plan) forecast_sales_report_detail.php (Sales Report)
แหล่งที่มาข้อมูล นำเข้าจากไฟล์ Excel (Template) ดึงจากฐานข้อมูลธุรกรรมโดยตรง (Live Query)
การคำนวณพื้นฐาน คำนวณใน Excel ( Formulas) ก่อนนำเข้า คำนวณด้วย SQL/PHP ขณะเปิดหน้าจอ
ความสดใหม่ เป็นข้อมูล Snapshot (ตามเวลาที่นำเข้าไฟล์) เป็นข้อมูลปัจจุบันตามฐานข้อมูล (Real-time)

2. รายละเอียดการคำนวณยอดขาย (Sales Metrics)

ยอดขาย 12 เดือนปีก่อนหน้า (Avg/Min/Max):
  • Tires Plan: ใช้ค่าคงที่จาก Excel ที่ถูกบันทึกลงคอลัมน์ avg_per_month_year, max_qty_year, min_qty_year
  • Sales Report: ดึงข้อมูลสรุปรายปีจาก SQL และแสดงผ่านคอลัมน์ avg_monthly_last_year
ยอดขายย้อนหลัง 3 เดือน:
  • Tires Plan: บันทึกแยกเป็น 3 คอลัมน์ (sales_month_1, 2, 3) โดยดึงค่าจากไฟล์ Excel
  • Sales Report: คำนวณหาเดือนย้อนหลัง 3 เดือนจากระบบ และดึงยอดขายสะสมรายเดือนมาแสดง

3. การหาค่าเฉลี่ยและเปอร์เซ็นต์ (Calculation Logic)

ค่าเฉลี่ย 3 เดือน:
  • Tires Plan: ใช้ค่าที่คำนวณมาแล้วจาก Excel (Column avg_3_month)
  • Sales Report: ใช้ฟังก์ชัน PHP round_avg_3month() เพื่อปัดเศษ (ถ้าเศษ >= 0.5 ปัดขึ้น)
การคำนวณ % และค่าเปรียบเทียบ:
  • Tires Plan: ข้อมูลเป็นค่าคงที่ (Static) ที่ถูกนำเข้ามาพร้อมไฟล์
  • Sales Report: คำนวณแบบ Interactive (JavaScript) เมื่อมีการแก้ตัวเลขในช่อง "คาดการณ์ยอดขาย" ระบบจะคำนวณค่าใหม่ทันทีที่หน้าจอ
  • สูตรคำนวณ: ((forecast_qty - avg_3month) / avg_3month) * 100

4. สรุปความแตกต่างหลัก

  • Tires Plan Display: เน้นการแสดงผลที่รวดเร็วและเป็นทางการตามเอกสาร Excel ที่อนุมัติมาแล้ว ข้อมูลจะไม่เปลี่ยนแปลงถ้าไม่มีการนำเข้าไฟล์ใหม่
  • Sales Report Detail: เน้นความยืดหยุ่นและการทำงานแบบโต้ตอบ (Interactive) เซลส์สามารถจำลองตัวเลขคาดการณ์และเห็นผลลัพธ์การเปรียบเทียบ % ได้ทันที
