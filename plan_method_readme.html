สรุปรายละเอียดการพัฒนาระบบ Tires Plan Forecast รูปแบบใหม่

1. ไฟล์ที่จัดทำขึ้นใหม่ (New System Components)

  • PHP forecast_plan_display_new.php: หน้าจอหลักสำหรับแสดงผลและแก้ไขข้อมูล (Interactive UI)
  • PHP forecast_plan_fetch_new.php: ระบบดึงข้อมูลเบื้องหลังที่รวมยอดขายจริงจาก Database (Live Data Engine)
  • PHP forecast_update_plan_new.php: ระบบบันทึกข้อมูลแบบกลุ่มลงฐานข้อมูล (Bulk Update Processor)

2. กลไกการดึงข้อมูล (Live Data Retrieval)

ระบบเปลี่ยนจากการดึงยอดขายคงที่จาก Excel มาเป็นการดึง ยอดขายจริง (Live Data) จากตาราง ims_data_sale_sac_all โดยใช้เงื่อนไขดังนี้:

  • Anchor Point: ใช้เดือน/ปี ที่ระบุตอน Import (forcast_month/year) เป็นตัวตั้งต้น
  • Dynamic Lookup: ระบบคำนวณเดือนย้อนหลัง M-1, M-2, M-3 อัตโนมัติจาก SQL Subquery
  • Data Matching: จับคู่ข้อมูลด้วย AR_CODE (ลูกค้า) และ SKU_CODE (สินค้า) เพื่อให้ยอดขายตรงตัว
  • Historical Average: คำนวณค่าเฉลี่ย 12 เดือนของปีก่อนหน้า (Last Year / 12) แบบ Real-time

3. หลักการคำนวณ (Logic & Calculation)

ใช้มาตรฐานการคำนวณเดียวกับหน้า Sales Report เพื่อความแม่นยำสูงสุด:

หัวข้อ สูตรการคำนวณ หมายเหตุ
ค่าเฉลี่ย 3 เดือน
(M1 + M2 + M3) / 3
 ใช้การปัดเศษ: เศษ >= 0.5 ปัดขึ้น, < 0.5 ปัดลง
ผลต่างคาดการณ์
Forecast - Avg3M
 คำนวณสดทันทีผ่าน JavaScript เมื่อมีการพิมพ์
% เทียบยอดขาย
(ผลต่าง / Avg3M) * 100
 แสดงผลเป็นตัวเลขจำนวนเต็มตามด้วยเครื่องหมาย %

4. ระบบ Interactive & Bulk Save

  • JS Real-time Logic: คอลัมน์ "เทียบคาดการณ์" และ "% เทียบยอดขาย" จะอัปเดตทันทีที่ผู้ใช้แก้ไขตัวเลขในช่อง "คาดการณ์"
  • PHP Bulk Saving: ระบบบันทึกข้อมูลแบบกลุ่ม (Batch Processing) ช่วยให้สามารถแก้ไขข้อมูลหลายบรรทัดพร้อมกันและบันทึกด้วยการกดปุ่มเพียงครั้งเดียว
  • SQL Transaction Mode: การบันทึกใช้ระบบ Transaction เพื่อป้องกันข้อมูลผิดพลาดหากเกิดปัญหาขณะ Update

5. ความปลอดภัยและการกรองข้อมูล (Role-Based Access)

ระบบยังคงรักษามาตรฐานความปลอดภัยตามสิทธิ์การใช้งาน (Account Type):

  • สิทธิ์ sale_user: จะเห็นและแก้ไขได้เฉพาะข้อมูลที่ตรงกับชื่อเซลส์ของตนเอง
  • สิทธิ์ take: จะเห็นและแก้ไขได้เฉพาะข้อมูลที่ตรงกับชื่อคนเทคของตนเอง
  • สิทธิ์ admin / อื่นๆ: สามารถดูและจัดการข้อมูลได้ทั้งหมดตามเงื่อนไขที่กำหนด
