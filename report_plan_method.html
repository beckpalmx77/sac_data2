แนวทางการจัดทำรายงานสรุปรายปี (Yearly Summary Report)

1. แนวคิดหลัก (Core Concept)

เนื่องจากการนำเข้าข้อมูล (Import) และการแก้ไข (Edit) ทำเป็นรายเดือน รายงานสรุปรายปีจึงมีหน้าที่ในการ "รวบรวม (Aggregate)" ข้อมูลจากทุกเดือนในปีนั้นๆ มาแสดงผลในรูปแบบที่เปรียบเทียบให้เห็นภาพรวมของทั้งปี เพื่อใช้ในการประเมินศักยภาพของพนักงานขายและแนวโน้มของลูกค้า

2. รูปแบบของรายงาน (Report Formats)

แบบที่ A: Yearly Dashboard (Pivot Table)

แสดงรายชื่อพนักงานขาย/ลูกค้า และมีคอลัมน์เป็นเดือน 1-12 เพื่อดู Target หรือ Forecast รวมทั้งปี

พนักงานขาย / ลูกค้าม.ค.ก.พ....ธ.ค.รวมทั้งปี
Sales A100120...1501,400

แบบที่ B: Comparison Summary

สรุปยอดรวมทั้งปีแยกตามหมวดหมู่ (เช่น ตามยี่ห้อ หรือ ตามทีม) โดยเปรียบเทียบ:

  • Yearly Target: เป้าหมายรวมทั้งปี
  • Yearly Forecast: ยอดคาดการณ์รวมทั้งปี
  • Achievement %: อัตราส่วนความสำเร็จ (Forecast vs Target)

3. วิธีการดึงข้อมูล (Data Retrieval Logic)

ใช้คำสั่ง SQL Group By ปี และ Month เพื่อดึงข้อมูลจาก ims_tires_plan_forecast:

SELECT
  sale_name,
  SUM(target_qty_month) as total_target,
  SUM(forecast_qty_month_1) as total_forecast,
  AVG(compare_sales_percent) as avg_achievement
FROM ims_tires_plan_forecast
WHERE forcast_year = '2025'
GROUP BY sale_name

4. ขั้นตอนการดำเนินงาน (Implementation Steps)

  1. สร้างหน้าจอ Filter: ให้เลือก "ปี" ที่ต้องการดูรายงาน (Default เป็นปีปัจจุบัน)
  2. ประมวลผลข้อมูล: สร้างไฟล์ forecast_report_yearly_fetch.php เพื่อคำนวณยอดรวม
  3. แสดงผล Interactive: ใช้ DataTable แสดงผลพร้อมปุ่ม Toggle ระหว่าง "ดูตามยอดเป้า" หรือ "ดูตามยอดคาดการณ์"
  4. ระบบส่งออก: เพิ่มปุ่ม "Export to Excel" เพื่อนำผลสรุปทั้งปีไปใช้งานต่อในรูปแบบไฟล์สรุปนิ่ง

5. ประโยชน์ที่ได้รับ

  • เห็นภาพรวมการเติบโตของแต่ละพื้นที่ (Zone/Province) ตลอดทั้งปี
  • ประเมินความแม่นยำในการคาดการณ์ของพนักงานขาย (Forecast Accuracy)
  • ใช้เป็นฐานข้อมูลในการตั้งเป้าหมาย (Quota Setting) สำหรับปีถัดไป
