📝 แผนการดำเนินงานและสคริปต์ปรับปรุงข้อมูลที่อยู่ลูกค้า

เอกสารฉบับนี้อธิบายแนวทาง ขั้นตอน และรายละเอียดของระบบซิงค์ที่อยู่ลูกค้า (อำเภอ, จังหวัด) จากมุมมองข้อมูลกลาง v_customer_data_sale_all_zone ไปยังตารางเป้าหมายแผนงาน ims_tires_plan_forecast โดยจับคู่ด้วยรหัสลูกค้า (AR_CODE)

1. ข้อมูลโครงสร้างตารางและวิวมุมมองที่เกี่ยวข้อง

  • ตารางเป้าหมาย (Destination): ims_tires_plan_forecast
    ฟิลด์เป้าหมายที่จะได้รับอัปเดต: amphur, province
  • วิวมุมมองต้นทาง (Source View): v_customer_data_sale_all_zone
    ฟิลด์ต้นทางที่ดึงข้อมูล: TRD_AMPHUR, TRD_PROVINCE
  • คีย์การเชื่อมโยง (Join Key): ar_code ในตารางแผนงานจับคู่กับ AR_CODE ในวิวมุมมองกลาง

2. แผนและขั้นตอนการทำงาน (Step-by-Step Implementation)

ขั้นตอนที่ 2.1: เตรียมไฟล์สคริปต์ระบบหลังบ้าน

สร้างไฟล์สคริปต์ PHP ชื่อ sync_address_from_zone.php อยู่ที่โฟลเดอร์ราก (Root Directory) ของโครงการเพื่อประมวลผลการทำงานผ่านเว็บ

ขั้นตอนที่ 2.2: กำหนดเงื่อนไขและความปลอดภัยข้อมูล (Data Safety)
  • กำหนดเงื่อนไข WHERE เพื่อดึงเฉพาะแถวข้อมูลต้นทางที่มีค่าอยู่จริง (ไม่เป็นค่าว่างหรือ NULL)
  • ใช้ระบบ Database Transaction เพื่อป้องกันข้อผิดพลาดในการบันทึกข้อมูลกึ่งกลางคัน หากคำสั่งล้มเหลวจะทำการยกเลิก (Rollback) ข้อมูลทั้งหมดเพื่อความปลอดภัย
  • ใช้ระบบสิทธิ์การเข้าใช้งาน session_start() เพื่อป้องกันบุคคลภายนอกที่ไม่ได้รับอนุญาตเข้ามารันสคริปต์นี้
ขั้นตอนที่ 2.3: ออกแบบชุดคำสั่ง SQL (SQL Join Update Query)

คำสั่ง SQL หลักที่ใช้ในระบบประมวลผลความเร็วสูง:

UPDATE ims_tires_plan_forecast p
INNER JOIN v_customer_data_sale_all_zone v ON p.ar_code = v.AR_CODE
SET 
    p.amphur = v.TRD_AMPHUR,
    p.province = v.TRD_PROVINCE
WHERE (v.TRD_AMPHUR IS NOT NULL AND v.TRD_AMPHUR != '')
   OR (v.TRD_PROVINCE IS NOT NULL AND v.TRD_PROVINCE != '')
ขั้นตอนที่ 2.4: หน้าจอแสดงผลลัพธ์และแถบความก้าวหน้า (Progress Bar)

สร้างหน้าจออินเตอร์เฟสหลักที่ update_addr_cust_display.php เพื่อให้ผู้ใช้งานเข้ามากดปุ่มเริ่มอัปเดตข้อมูลได้สะดวก โดยระบบจะเรียกงานหลังบ้านผ่าน AJAX ไปยัง sync_address_from_zone_ajax.php และแสดงแถบความก้าวหน้ารวมถึงพิมพ์บันทึก System Log ให้เห็นขั้นตอนการทำงานแบบสด ๆ

3. ไฟล์สคริปต์และหน้าจอที่เกี่ยวข้อง

  • หน้าจออินเตอร์เฟสหลัก: update_addr_cust_display.php
  • สคริปต์ประมวลผล AJAX: sync_address_from_zone_ajax.php
  • สคริปต์ประมวลผลแบบรันตรง (Direct Script): sync_address_from_zone.php
