ระบบเชื่อมโยงข้อมูลลูกค้าและทีมขาย

แนวทางและขั้นตอนการปรับปรุงข้อมูลเซลส์ คนเทค และภูมิศาสตร์ ไปยังตารางวางแผนการขายยาง

1. วัตถุประสงค์ของการเชื่อมต่อตาราง

ต้องการนำข้อมูลรายละเอียดของลูกค้า ได้แก่ ชื่อพนักงานขาย (sale_name), ชื่อคนเทค (take_name), อำเภอ (amphur), และจังหวัด (province) จากตารางข้อมูลลูกค้ากลาง ims_data_sale_sac_all ไปปรับปรุงลงในตารางแผนงานหลัก ims_tires_plan_forecast โดยใช้ AR_CODE ของร้านค้าเป็นคีย์เชื่อมโยง (Key Link)

ประโยชน์: ช่วยลดขั้นตอนการนำเข้าซ้ำซ้อน และลดโอกาสเกิดช่องว่างของข้อมูล (Null/Empty) เมื่อผู้ใช้งานเพิ่มรายการแผนการขายใหม่
2. คำสั่ง SQL สำหรับการอัปเดต (MySQL Update Join)

รันคำสั่ง SQL ด้านล่างนี้บนระบบฐานข้อมูล (phpMyAdmin หรือเครื่องมือจัดการ DB อื่นๆ) เพื่อเชื่อมโยงและปรับปรุงข้อมูลย้อนหลัง:

UPDATE ims_tires_plan_forecast p
INNER JOIN (
    SELECT 
        AR_CODE, 
        MAX(SALE_NAME) AS SALE_NAME, 
        MAX(TAKE_NAME) AS TAKE_NAME, 
        MAX(TRD_AMPHUR) AS TRD_AMPHUR, 
        MAX(TRD_PROVINCE) AS TRD_PROVINCE
    FROM ims_data_sale_sac_all
    GROUP BY AR_CODE
) s ON p.ar_code = s.AR_CODE
SET 
    p.sale_name = s.SALE_NAME,
    p.take_name = s.TAKE_NAME,
    p.amphur = s.TRD_AMPHUR,
    p.province = s.TRD_PROVINCE;
* หมายเหตุ: มีการใช้ฟังก์ชัน MAX() เพื่อจับกลุ่มแถวตาม AR_CODE ให้เหลือบรรทัดเดียว ป้องกันเออเร่อใน MySQL Strict Mode
3. วิธีการนำไปรวมในหน้าจอนำเข้า Excel (Auto Sync)

เพื่อให้ข้อมูลซิงก์โดยอัตโนมัติเมื่อมีการนำเข้าไฟล์ Excel ให้แก้ไขไฟล์ประมวลผลหลังบ้านตามขั้นตอนดังนี้:

1 เปิดไฟล์ประมวลผลนำเข้าลูกค้าที่เส้นทาง: import_process/update_data_cust_sale_sac_process.php
2 เลื่อนไปส่วนท้ายของบล็อกคำสั่งนำเข้า (ก่อนแถวส่งคืนข้อความสำเร็จหรือประมาณบรรทัดที่ 108-110)
3 แทรกคำสั่ง PHP รันคำสั่ง SQL ซิงก์ข้อมูลดังนี้: 
// ซิงก์ข้อมูลไปยังตาราง forecast
$sql_sync = "UPDATE ims_tires_plan_forecast p
             INNER JOIN (
                 SELECT AR_CODE, MAX(SALE_NAME) AS SALE_NAME, MAX(TAKE_NAME) AS TAKE_NAME, 
                        MAX(TRD_AMPHUR) AS TRD_AMPHUR, MAX(TRD_PROVINCE) AS TRD_PROVINCE
                 FROM ims_data_sale_sac_all GROUP BY AR_CODE
             ) s ON p.ar_code = s.AR_CODE
             SET p.sale_name = s.SALE_NAME, p.take_name = s.TAKE_NAME, 
                 p.amphur = s.TRD_AMPHUR, p.province = s.TRD_PROVINCE";
$stmt_sync = $conn->prepare($sql_sync);
$stmt_sync->execute();
4. การเรียกใช้อัปเดตย้อนหลังแบบกดเอง (Manual Sync Script)

กรณีต้องการสั่งประมวลผลข้อมูลเก่าที่มีอยู่แล้วในระบบ สามารถสร้างไฟล์สคริปต์แยกเฉพาะชื่อ sync_cust_to_forecast.php ไว้ที่ Root Directory และรันผ่าน URL ของเว็บบราวเซอร์ได้ทันที
