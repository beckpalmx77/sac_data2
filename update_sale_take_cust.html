Database & Process Update

📋 รายงานสรุปการปรับปรุงระบบซิงก์พนักงานขาย และ คนเทคสินค้า

ข้อมูลการทำงาน: เอกสารฉบับนี้จัดทำขึ้นเพื่อสรุปการสร้าง/แก้ไข SQL View v_sale_cust_sac เพื่อเพิ่มฟิลด์ TAKE_NAME และการแก้ไขไฟล์โปรแกรมที่เกี่ยวข้อง เพื่อให้ระบบทำการซิงก์ข้อมูลพนักงานขาย และ คนเทคสินค้า (Sale Name & Take Name) เข้าตารางวางแผน ims_tires_plan_forecast โดยอัตโนมัติ

1. การปรับปรุงฐานข้อมูล (SQL View)

แก้ไขและสร้าง SQL View ใหม่: v_sale_cust_sac

ทำการแก้ไขโครงสร้าง View เดิม เพื่อดึงฟิลด์ TAKE_NAME เพิ่มเข้ามาจากตารางเก็บประวัติยอดขาย ims_data_sale_sac_all และจัดกลุ่ม (Group By) ข้อมูลลูกค้า:

CREATE OR REPLACE VIEW `v_sale_cust_sac` AS 
SELECT 
    `ims_data_sale_sac_all`.`AR_CODE` AS `AR_CODE`,
    `ims_data_sale_sac_all`.`AR_NAME` AS `AR_NAME`,
    `ims_data_sale_sac_all`.`SALE_NAME` AS `SALE_NAME`,
    `ims_data_sale_sac_all`.`TAKE_NAME` AS `TAKE_NAME` 
FROM `ims_data_sale_sac_all` 
GROUP BY 
    `ims_data_sale_sac_all`.`SALE_NAME`,
    `ims_data_sale_sac_all`.`TAKE_NAME`,
    `ims_data_sale_sac_all`.`AR_CODE`,
    `ims_data_sale_sac_all`.`AR_NAME` 
ORDER BY 
    `ims_data_sale_sac_all`.`AR_CODE`,
    `ims_data_sale_sac_all`.`SALE_NAME`;

2. แฟ้มสะสมงานที่ได้รับการแก้ไข

1) การนำเข้าข้อมูลแผนยอดขาย (Import Process)

ไฟล์ที่แก้ไข: import_process/import_forecast_process.php

การทำงาน: หลังจากที่ข้อมูลไฟล์ Excel ถูกจัดเก็บลงฐานข้อมูลเสร็จสิ้น ก่อนจะเรียกใช้งาน $conn->commit() ระบบจะสั่งรันอัปเดตข้อมูลพนักงานขาย และคนเทคสินค้าจาก View ตัวใหม่โดยระบุเจาะจงเฉพาะช่วงเดือนและปีที่ทำงานการนำเข้า เพื่อความรวดเร็วและแม่นยำ

UPDATE ims_tires_plan_forecast p
INNER JOIN v_sale_cust_sac v ON p.ar_code = v.AR_CODE
SET 
    p.sale_name = v.SALE_NAME,
    p.take_name = v.TAKE_NAME
WHERE p.forcast_month = ? AND p.forcast_year = ?
  AND (v.SALE_NAME IS NOT NULL AND v.SALE_NAME != '' 
       OR v.TAKE_NAME IS NOT NULL AND v.TAKE_NAME != '')
2) การคัดลอกแผนไปยังเดือนใหม่ (Copy Month Process)

ไฟล์ที่แก้ไข: forecast_copy_month_process.php

การทำงาน: เมื่อทำการสำเนาคัดลอกข้อมูลยอดคาดการณ์เป้าจากเดือนเก่าไปเดือนใหม่เสร็จสิ้น ระบบจะเรียกการซิงก์ข้อมูลพนักงานขาย และคนเทคสินค้าล่าสุด ลงในแถวรายการของเดือน/ปีเป้าหมายใหม่ทันที

3) การปรับปรุงข้อมูลผ่านหน้าแสดงผลหลัก (Manual Sync Process)

ไฟล์ที่แก้ไข: sync_address_from_zone_ajax.php และ sync_address_from_zone.php

การทำงาน: ปรับปรุงปุ่ม "เริ่มอัปเดตข้อมูล" ในหน้าจอ update_addr_cust_display ให้มีความสามารถเพิ่มเติม โดยนอกจากจะปรับปรุงอำเภอและจังหวัดของลูกค้าแล้ว ระบบจะทำการดึงข้อมูลพนักงานขาย (Sale) และคนเทคสินค้า (Take) ล่าสุดไปเขียนทับลงในเป้าหมายแผนงานเดิมให้เป็นปัจจุบันที่สุดในคราวเดียวกันด้วย

4) การปรับปรุงส่วนหน้ากากผู้ใช้งาน (User Interface Updates)

ไฟล์ที่แก้ไข: update_addr_cust_display.php

การทำงาน: อัปเดตอินเตอร์เฟสผู้ใช้งานให้ระบุรายละเอียดในการซิงก์ข้อมูลเพิ่มเติม ปรับชื่อหัวเรื่องและคำอธิบายเป็น "ระบบปรับปรุงข้อมูลลูกค้า (ที่อยู่ & พนักงานขาย & คนเทค)" แสดงฟิลด์ที่จะถูกแก้ ได้แก่ amphur, province, sale_name และ take_name พร้อมทั้งแสดงแหล่งข้อมูลอ้างอิงของวิวทั้ง 2 ชิ้น และเพิ่มปุ่มยกเลิกการทำงานเพื่อย้อนกลับไปยังหน้าหลักอย่างสวยงาม

3. โครงสร้างตารางผลลัพธ์

  • ตารางที่ได้รับข้อมูล: ims_tires_plan_forecast

  • ฟิลด์ปลายทางผู้เทคสินค้า: take_name
