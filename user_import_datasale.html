คู่มือการใช้งาน หน้าจอนำเข้าข้อมูลการขาย SAC

ระบบจัดการเอกสารนำเข้าข้อมูลยอดขายทางธุรกิจของ บริษัท ส.อรุณ คอนกรีต จำกัด (SAC)

1. ภาพรวมระบบ (System Overview)

หน้าจอ import_data_sale_sac.php ถูกออกแบบขึ้นเพื่อให้เจ้าหน้าที่ผู้ดูแลระบบหรือฝ่ายขายที่ได้รับอนุญาต สามารถนำเข้าไฟล์รายงานยอดขายประจำวัน/ประจำเดือน ซึ่งบันทึกในรูปแบบไฟล์ Excel (นามสกุล .xlsx หรือ .xls) เข้าสู่ฐานข้อมูลหลักของระบบอย่างรวดเร็ว โดยไม่จำเป็นต้องคีย์ข้อมูลทีละรายการ

นอกจากนี้ หน้าจอยังมีฟังก์ชันสำหรับจัดการข้อมูลแบบครอบคลุม เช่น การเรียกดูบันทึกประวัติการนำเข้าล่าสุด การลบข้อมูลผิดพลาดแบบระบุวันที่ และการลิงก์เชื่อมต่อเพื่อสืบค้นข้อมูลโดยละเอียดผ่านหน้าต่างป๊อปอัป

ระบบรักษาความปลอดภัยและสิทธิ์การใช้งาน
หน้าจอนี้มีการตรวจสอบสิทธิ์ความปลอดภัยในระบบ (Session) หากผู้ใช้งานไม่ได้ทำการเข้าสู่ระบบผ่านการตรวจสอบ (ไม่มีตัวแปร alogin หรือ sale_name_id) ระบบจะปฏิเสธการเข้าถึงและนำกลับไปยังหน้าล็อกอิน index.php ทันทีเพื่อความปลอดภัยของข้อมูล

3. ขั้นตอนการนำเข้าไฟล์ข้อมูลการขาย (Excel Data Import Steps)

ทำตามขั้นตอนดังต่อไปนี้เพื่อนำเข้าข้อมูลอย่างถูกต้องเข้าสู่ฐานข้อมูลหลัก:

01
1. ดาวน์โหลดเทมเพลต
คลิกปุ่ม "ตัวอย่างไฟล์ Excel Format Data สำหรับนำเข้า" เพื่อดาวน์โหลดรูปแบบการจัดเก็บข้อมูลยอดขายที่เป็นมาตรฐานของระบบ
02
2. เตรียมเอกสารข้อมูล
เปิดไฟล์ Excel และบันทึกข้อมูลยอดขายลงในชีตงานให้ตรงตามจำนวน ลำดับ และชนิดตัวแปรของคอลัมน์มาตรฐาน 37 คอลัมน์ (ห้ามสลับคอลัมน์)
03
3. เลือกไฟล์เข้าระบบ
ที่หน้าจอหลัก ส่วนหัวข้อ "Select Excel File" ให้คลิกที่ช่องเลือกไฟล์ แล้วสืบค้นหาไฟล์เอกสาร Excel ที่ต้องการนำเข้าในคอมพิวเตอร์ของคุณ
04
4. กดนำเข้าข้อมูล
คลิกปุ่ม "Import" ตัวอักษรสีขาวพื้นหลังสีน้ำเงิน ระบบจะเริ่มทำงานแสดงสปินเนอร์หมุน ให้รอจนกว่าจะมีข้อความป๊อปอัปยืนยันผลลัพธ์
เมื่อนำเข้าข้อมูลเสร็จสมบูรณ์
ตารางรายการข้อมูลการนำเข้าด้านล่าง (DataTable) จะถูกโหลดข้อมูลขึ้นมาใหม่โดยอัตโนมัติ (Auto-reload) ทันที เพื่อให้คุณตรวจสอบรายการที่นำเข้าล่าสุดได้แบบเรียลไทม์

4. การลบข้อมูลแยกตามวันที่ (Delete Import Data By Date)

ในกรณีที่นำเข้าข้อมูลผิดพลาด หรือยอดขายของวันที่ใดๆ มีข้อมูลไม่สมบูรณ์ ผู้ใช้สามารถล้างข้อมูลยอดขายทั้งวันของวันนั้นๆ เพื่อรอการนำเข้าใหม่ได้

ข้อควรระวังสูงสุด
การดำเนินการลบข้อมูลตามวันที่ จะลบแถวรายการยอดขายของวันที่ระบุนั้น "ทั้งหมดทุกรายการ" ออกจากฐานข้อมูลของบริษัท และการลบนี้จะสำเร็จทันทีแบบไม่มีวิธีกู้คืน (Undo) ยอดขายกลับมาได้หลังจากลบแล้ว กรุณาตรวจสอบวันที่ยืนยันอย่างเข้มงวด

ขั้นตอนการลบข้อมูลการขาย:

  1. เลื่อนลงไปที่กล่องเมนูการจัดการข้อมูล (ล่างปุ่มนำเข้า)
  2. คลิกปฏิทินที่ช่อง "เลือกวันที่ที่จะลบ" เลือกวัน เดือน ปี ค.ศ. ที่ต้องการประมวลผลลบข้อมูล
  3. คลิกปุ่มสีแดง "ลบข้อมูลตามวันที่"
  4. ระบบจะแสดงกล่องแจ้งเตือน Pop-up แจ้งคำยืนยัน เช่น "คุณต้องการลบข้อมูลวันที่ DD-MM-YYYY จริงหรือไม่?"
  5. กดตกลง (OK) เพื่อยืนยันการลบ หรือ ยกเลิก (Cancel) เพื่อถอยกลับ
  6. เมื่อระบบลบข้อมูลเสร็จสิ้น จะแสดงผลสถานะแจ้งเตือนจำนวนแถวที่ลบไป และตารางรายการด้านล่างจะอัปเดตรีเฟรชผลลัพธ์ทันที

5. การดูและค้นหาข้อมูลละเอียด (Popup Details & Query Screen)

เพื่อหลีกเลี่ยงการสืบค้นข้อมูลที่ทำให้หน้าจอหลักช้าลง ระบบได้แยกหน้าแสดงข้อมูลไว้อีกหนึ่งหน้าจอคือ display_import_data_sale_sac.php ซึ่งจะเปิดขึ้นในแท็บหรือหน้าต่างใหม่

วิธีการใช้งานหน้าต่างแสดงข้อมูลนำเข้าย่อย (Popup Display Window):

  1. คลิกที่ปุ่มสีฟ้า "ดูข้อมูลตามวันที่" (มีไอคอนแว่นขยาย) บนหน้าจอหลัก
  2. ระบบจะเปิดหน้าต่างใหม่ในเว็บเบราว์เซอร์ ซึ่งจะแสดงข้อมูลประวัติของวันนี้ (Today) เป็นค่าเริ่มต้นโดยอัตโนมัติ
  3. หากต้องการค้นหาวันที่อื่น:
    • คลิกเปลี่ยนวันที่ในช่อง เลือกวันที่ (DI_DATE)
    • ระบบจะทำการดึงข้อมูลใหม่มาแสดงในตารางแบบเรียลไทม์ทันทีเมื่อมีการคลิกเปลี่ยนวันที่
    • หรือคลิกปุ่ม "ค้นหา" (สีน้ำเงิน) เพื่อค้นหาด้วยตนเอง
  4. คลิกปุ่ม "รีเซ็ตเป็นวันนี้" (สีเทา) เพื่อย้อนกลับมาที่ข้อมูลของวันปัจจุบันได้อย่างรวดเร็ว
  5. ฟังก์ชันลบข้อมูลด่วน: สามารถคลิกปุ่มสีส้ม/เหลือง "ลบข้อมูลตามวันที่" เพื่อทำการลบประวัติเฉพาะวันที่คุณกำลังเปิดแสดงอยู่ ณ ขณะนั้นได้ทันที
  6. คลิกปุ่ม "ปิดหน้าต่าง" (สีแดง) เมื่อต้องการยุติการสืบค้นและปิดหน้าต่างย่อยนี้ลง
กรณีปุ่มดูข้อมูลตามวันที่ใช้งานไม่ได้
หากคลิกปุ่ม "ดูข้อมูลตามวันที่" แล้วไม่มีอะไรเกิดขึ้น โปรดตรวจสอบว่าเว็บเบราว์เซอร์ของคุณมีการบล็อกป๊อปอัป (Popup Blocker) หรือไม่ ให้กดอนุญาตการเปิดหน้าต่างสำหรับโดเมนเว็บไซต์นี้เสมอ

6. รูปแบบโครงสร้างไฟล์ Excel นำเข้า (Standard Template Specifications)

เพื่อป้องกันไม่ให้การรันสคริปต์ PHP เกิดความล้มเหลว ไฟล์ข้อมูล Excel ที่นำเข้าจะต้องประกอบด้วยคอลัมน์มาตรฐานทั้งหมด 37 คอลัมน์ (Index 0 ถึง 36) โดยห้ามลบ ย้าย หรือเพิ่มหัวคอลัมน์ใดๆ เข้ามา ตารางด้านล่างแสดงโครงสร้างคอลัมน์สำคัญที่ระบบประมวลผล:

คอลัมน์ (Index) รหัสตัวแปรระบบ รายละเอียดข้อมูล ชนิดข้อมูล (Data Type) ตัวอย่างข้อมูล
A (0) DI_DATE_BLANK วันที่เอกสาร (วันที่ต้นทางจากไฟล์) String / Date 19-06-2026
B (1) DI_DAY วันที่ขาย (เฉพาะตัวเลขวัน 1-31) Numeric 19
C (2) DI_MONTH_NAME ชื่อย่อหรือชื่อเต็มของเดือน String มิ.ย. / Jun
D (3) DI_YEAR ปี ค.ศ. (ตัวเลข 4 หลัก) Numeric 2026
E (4) AR_CODE รหัสลูกค้า / รหัสสมาชิกร้านค้า String AR-00421
F (5) SKU_CODE รหัสสินค้าหลัก String TIRE-MICH-001
G (6) SKU_NAME ชื่อสินค้าอย่างละเอียด String ยาง Michelin Primacy 4 205/55R16
H (7) DETAIL รายละเอียดเพิ่มเติมของสินค้า String ยางรถยนต์ขอบ 16 นิ้ว
I (8) BRAND ยี่ห้อ / แบรนด์สินค้า String MICHELIN
J (9) DI_REF เลขที่ใบกำกับภาษี / เลขที่เอกสารการขาย Required IV-69123001
K (10) AR_NAME ชื่อ-นามสกุลลูกค้า / ชื่อร้านค้า String ร้านนำชัยยางยนต์

P (15) TRD_QTY จำนวนสินค้าที่ขาย Numeric 4.00
Q (16) TRD_PRC ราคาขายต่อหน่วยสินค้า Numeric 3200.00
R (17) TRD_DISCOUNT ส่วนลดรวมประจำรายการ Numeric 500.00
S (18) TRD_TOTAL_PRICE มูลค่าขายรวมก่อนภาษี (Subtotal) Numeric 12800.00
T (19) TRD_VAT ภาษีมูลค่าเพิ่ม (VAT 7%) Numeric 861.00
U (20) TRD_AMOUNT_PRICE จำนวนเงินขายสุทธิรวมภาษี (Net Price) Numeric 13161.00
V (21) TRD_PER_POINT คะแนนสะสมที่ได้ต่อชิ้นสินค้า Numeric 10.00
W (22) TRD_TOTAL_POINT คะแนนสะสมรวมของรายการ Numeric 40.00
X (23) WL_CODE รหัสคลังสินค้าเบิกจ่าย String WH-TIRE01
Y (24) TRD_Q_FREE จำนวนของแถม (กรณีแจกฟรี) Numeric 0
Z (25) TRD_AMPHUR อำเภอ (ที่ตั้งลูกค้า) String สามพราน
AA (26) TRD_PROVINCE จังหวัด (ที่ตั้งลูกค้า) String นครปฐม
AB (27) TRD_MARK หมายเหตุการส่งสินค้า (Zone) String ส่งหน้างานเฟส 2

7. ปัญหาที่พบบ่อยและข้อควรระวัง (Troubleshooting & Caveats)

หากคุณพบข้อผิดพลาดหรือปัญหาเกี่ยวกับการทำงานของระบบระหว่างการใช้งานหน้าจอนำเข้าข้อมูลยอดขาย ให้ลองตรวจสอบแนวทางแก้ไขดังต่อไปนี้:

เกิดข้อผิดพลาด "Invalid file type"

ระบบนี้อนุญาตให้นำเข้าเฉพาะไฟล์ที่ตรวจพบชนิดข้อมูลแบบ Excel (.xlsx และ .xls) เท่านั้น หากบันทึกไฟล์เป็น PDF, CSV, Word หรือรูปภาพ ระบบจะตรวจจับและยกเลิกกระบวนการอัปโหลดอัตโนมัติ วิธีแก้คือให้ตรวจสอบนามสกุลของไฟล์งานและทำการบันทึกข้อมูลเป็น Excel Worksheet เสมอ

นำเข้าข้อมูลแล้ว ตัวเลขหรือจำนวนแสดงเป็นศูนย์ (0)

หากข้อมูล เช่น ยอดเงิน หรือ จำนวนขาย มีการขึ้นเครื่องหมายผิดพลาดทางสูตร เช่น #N/A หรือ #REF! ระบบนำเข้าอัจฉริยะจะทำการกรองและแปลงค่าผิดพลาดเหล่านั้นให้กลายเป็นตัวเลข 0 ทันทีเพื่อป้องกันไม่ให้โครงสร้างฐานข้อมูลเสียหาย โปรดตรวจสอบสูตรการคำนวณและข้อมูลต้นทางใน Excel ให้ไม่มีค่า Error ก่อนการนำเข้า

หน้าจอค้าง หรือขึ้นแจ้งเตือน Timeout ในการอัปโหลดไฟล์ขนาดใหญ่

ฝั่งเซิร์ฟเวอร์ได้รับการตั้งค่าให้รองรับการทำงานแบบยาวนานโดยไม่จำกัดเวลา (set_time_limit(0)) และขยายหน่วยความจำสำหรับไฟล์ขนาดใหญ่ถึง 2GB (memory_limit 2048M) แต่หากอินเทอร์เน็ตของผู้ใช้งานไม่เสถียร อาจส่งผลให้เว็บเบราว์เซอร์หยุดตอบสนอง แนะนำให้แบ่งย่อยไฟล์ยอดขายหากมีขนาดใหญ่เกินกว่า 30,000 แถว หรือติดต่อผู้ดูแลระบบเน็ตเวิร์กเพื่อช่วยนำเข้า

ข้อมูลการขายไม่แสดงในตารางหลังนำเข้าสำเร็จ

ระบบมีกลไกป้องกันการนำเข้าข้อมูลซ้ำ (Duplicate Prevention) โดยตรวจสอบคีย์สำคัญของรายการ เช่น วันที่, เลขที่เอกสาร, รหัสสินค้า, จำนวนขาย และมูลค่าเงินสุทธิ หากตรวจสอบแล้วพบว่าแถวนั้นมีอยู่แล้วในระบบอย่างสมบูรณ์ รายการดังกล่าวจะไม่ถูกนำเข้าเพิ่มเพื่อป้องกันข้อมูลทับซ้อนและข้อมูลไม่ตรงตามจริง
